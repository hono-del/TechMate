## 2. F1 + F4 Diagnosis

### 2.1 表示のきっかけ / When recommendations appear

**日本語**

- 画面を開いた直後は Possible Causes と Recommended Diagnostic Flow は空。パネル自体は残し、プレースホルダだけ出す。
- DTC に 1 文字入れただけでは出ない。Optional scan で P0420 が入っても、**Save input を押すまで出ない**。
- 受付情報だけでは埋めない。診断画面で Save した内容が先。
- 照合できない入力で Save すると、「このモックで照合できる内容がありません」と出す。

**English**

- On open, Possible Causes and Recommended Diagnostic Flow stay empty. Panels remain with placeholders.
- A single DTC character does **not** show recommendations. Optional scan filling P0420 also waits for **Save input**.
- Reception data alone does not fill the panels.
- Save with unmatched input shows a no-match hint for this mock.

### 2.2 並び / Layout (F4)

左 → 中央 → 右 の読み順。

Left → center → right reading order.

```text
Manual diagnosis input（手入力 4 項目 + Save input）
        ↓
Recommended Diagnostic Flow（左）  →  ステップ詳細（中央）  →  Possible Causes（右）
        ↓
Confirm Cause & Create Work Plan
```

点検の手順を先に見せ、原因カードはフローのあとに選ぶ、という意図です。フロー未完了でもカードは選べます（デモが止まらないようにするため）。

The flow is the starting point; cause cards come after checks. Cards are not locked until the flow is done (so the demo does not stall).

### 2.3 デモケース A — P0420（DTC から引く） / Demo A — P0420

1. Technician（山本 健司）で Diagnosis を開く。
2. DTC に `P0420`（`P420` でも可）を入れる。この時点では候補は出ない。
3. **Save input** を押す。

**Possible Causes**

- Catalytic converter efficiency below OEM threshold（High）
- Downstream O2 sensor (bank 1 sensor 2) malfunction（Medium）
- Exhaust leak upstream of catalyst（Low）

**Recommended Diagnostic Flow**

1. Check for related DTCs
2. Inspect exhaust system
3. Check sensor data
4. Inspect related component
5. Confirm diagnosis

ステップをクリックすると、What to Check / Service Manual §EC-4 / TIE #2022-0188 などが出ます。

Click a step for What to Check, Service Manual §EC-4, TIE #2022-0188, and similar.

### 2.4 デモケース B — 段差ガタ音（DTC なし） / Demo B — rattling over bumps, no DTC

DTC から答えを引けないケースです。症状と発生条件から複数原因を考える、TechMate らしい流れを見せます。

This case cannot be answered from a DTC. The mock shows symptom → AI ranking → causes → flow → Manual / TIE / Q&A.

1. DTC 欄は **空** のままにする（P0420 が残っていたら消す）。
2. Failure symptom に次を入れる。

```text
Rattling noise from the front of the vehicle when driving over bumps. No warning light and no DTC detected.
```

日本語でも同じセットになります（例: 「段差を乗り越えた際に、車両前方からガタガタという異音がする。警告灯の点灯はなく、DTCも検出されない。」）。

The same set appears for Japanese wording (e.g. ガタガタ / 段差 / 前方の異音).

3. **Save input** を押す。P0420 の候補は消えて、次のセットに切り替わる。

**Possible Causes**

- Stabilizer link or bushing wear（High）
- Strut mount deterioration（Medium）
- Suspension bushing wear（Medium）
- Loose suspension component（Medium）
- Underbody / shield component looseness（Low）

**Recommended Diagnostic Flow**

1. Reproduce the symptom — 同様の路面で再現する
2. Identify the approximate location — 前左 / 前右 / 中央、ステアリング・制動で変わるか
3. Perform visual inspection — サス・ブッシュ・取付部の損傷・緩み
4. Check related components — 可能性の高い原因に関連する部品
5. Compare findings with similar cases — TIE / Q&A / 過去修理
6. Confirm the most likely cause — 所見を記録して原因を確定

ステップ詳細の例: Service Manual §SA-12、TIE #2023-1104（スタビライザーリンク交換）、Q&A #9044（ロアアームブッシュ）。

Step details include Service Manual §SA-12, TIE #2023-1104 (stabilizer link), Q&A #9044 (lower-arm bushing).

```text
Failure symptom
  ↓
AI understands the symptom and conditions（Save input）
  ↓
Possible Causes（右）
  ↓
Recommended Diagnostic Flow（左）＋ ステップ詳細（Manual / TIE / Q&A）
  ↓
Confirm Cause
```

DTC が入っていると P0420 側が優先されます。ガタ音デモの前に DTC を空にしてください。

If a P0420-like DTC is present, that scenario wins. Clear DTC before the rattle demo.

## 3. F3 Check & Verify

**日本語**

- Customer concerns / requests を、Recommended Verification（チェックリスト等）の **下、フッター直前** に移した。
- 技術項目を先に潰し、最後に受付内容と突き合わせる読み順。
- 操作ルールは 11/24 のまま。Resolved / Action decided / Pending。Action decided は対応内容が必須。未完了なら Create Work / Explanation Note は押せない。
- 修理サマリーはページ先頭のまま。

**English**

- Customer concerns / requests sit below Recommended Verification, just above the sticky footer.
- Technical checks first, reception items as final confirmation.
- Same rules as 11/24: Resolved / Action decided / Pending. Action decided still needs a note. CTA stays blocked until required items are done.
- Repair summary stays at the top.

## 4. F2 Handover（整備士） / F2 Handover for technicians

**日本語**

- フロア整備士（山本 健司）のステッパーで **6. Handover は表示するがグレー。クリック不可**。
- 工程の全体像は残す（非表示にはしない）。
- `/job/job-001/handover` を直接開いても入れない。Work / Explanation Note へ戻す。
- SA（鈴木 はるか）/ Dealer Administrator / System Administrator はこれまでどおり開ける。Complete Job もこのロール。
- Technician Manager（中村 涼）の Handover はグレーにしない（F5 のレビュー受け取り）。顧客返却の Complete Job は押せない。

**English**

- Floor technician sees step 6 grayed out and cannot click it. The six-step picture stays visible.
- Direct URL to handover redirects to Work / Explanation Note.
- SA / Dealer Administrator / System Administrator still open Handover and Complete Job.
- Technician Manager can open Handover for review (F5) but does not Complete Job (customer return stays with SA / Admin).

## 5. F5 Submit for Review → Technician Leader

**日本語**

- 整備士が Work / Explanation Note で **Submit for Review** すると、待ち先は SA ではなく **Technician Leader**。
- このモックの Leader は Technician Manager（中村 涼）。
- 中村 涼で Home を開くと、対象ジョブが **Pending Handover** として他の In Progress より目立って出る。カードから説明ノートのレビュー（Handover）を開ける。
- 顧客への車両返却（Complete Job）は、Leader レビューのあとも SA / Admin。

**English**

- After Submit for Review, the work order routes to **Technician Leader**, not SA first.
- Leader in this mock = Technician Manager (Ryo Nakamura).
- Ryo’s Home shows the job as a highlighted **Pending Handover** task, above other In Progress items. The card opens note review (Handover).
- Complete Job (vehicle return) remains SA / Admin after Leader review.
